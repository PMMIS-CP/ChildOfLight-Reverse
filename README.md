# CKD Extractor & Converter for Child of Light (Ubisoft)

![Python Version](https://img.shields.io/badge/Python-3.8%2B-blue)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)
![Status](https://img.shields.io/badge/Status-Active-success)

**CKD Extractor** is a command-line tool to extract and convert proprietary **CKD files** from *Child of Light* (Ubisoft / UbiArt Framework) into **standard, editable formats** for Unity, Blender, Photoshop, and other industry-standard tools.

## 🎯 Purpose

This tool unlocks game assets by converting CKD files to widely supported formats, making them viewable and editable in common software.

## ✅ Supported Conversions (CKD → Standard Formats)

| Works correctly | Format |
|----------------|--------|
| ✔️ | `png.py` → `.png` |
| ✔️ | `tga.py` → `.tga` |
| ❌ (In progress) | `a3d.py`, `act.py`, `anm.py`, `asc.py`, `fcg.py`, `frt.py`, `gmt.py`, `isc.py`, `isg.py`, `m3d.py`, `mcd.py`, `mcloth.py`, `msh.py`, `pbk.py`, `s3d.py`, `sgs.py`, `skl.py`, `tfn.py`, `tpl.py`, `tsc.py` |

> All formats will eventually be converted to **standard editable formats** (e.g., `.obj`, `.fbx`, `.json`, `.wav`).  

## 🚀 Future Goal

Convert **all CKD assets** (models, animations, textures, skeletons) into formats usable in **Unity**, **Godot**, **Unreal Engine**, and other standard engines — to fully reconstruct or mod *Child of Light* with open tools.
